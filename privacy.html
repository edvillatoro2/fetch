Privacy Policy

Last updated: March 30, 2026

Overview

Fetch is a Chrome extension that allows users to browse and filter their YouTube liked videos by category.

Data collection

Fetch does not collect, store, or transmit any personal data to external servers.

YouTube data

Fetch accesses your YouTube liked videos using the YouTube Data API v3 with read-only permissions. This data is:

  • Stored locally in your browser only
  • Never transmitted to any external server
  • Never shared with third parties
  • Used solely to display your liked videos within the extension

Authentication

OAuth tokens are stored locally in your browser's chrome.storage and are used solely to authenticate with YouTube's API. Tokens are never sent to any server other than Google's OAuth servers.

Third parties

Fetch does not share any data with third parties. The only external service used is the YouTube Data API v3, operated by Google.
